# create-automation
Create: Automation adds a numerical signal network, configurable controllers, RPM/redstone I/O, and a System Builder with PID, filters, delays, and live plots. Sable height/speed/attitude detectors and a transfer-function configurator enable control experiments. Includes 13 blocks, 5 Ponder scenes; MC 1.21.1, NeoForge, Create 6.0.10, MIT.
